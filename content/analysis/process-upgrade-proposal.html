Phase 2: Brief Files

2
Create and update the brief documents
The reference materials that all skills and grading depend on. Must be done before new skills can work.

create brief/voice.md — Voice DNA document

The target voice for all module writing. Built from Module 08 v2.

Option A: Install the voiceprint skill (jamesckemp/claude-plugins), run it with 5 excerpts from Module 08 v2 and your own writing, edit the output.

Option B: Write manually. Include:
  • 3-5 exemplar paragraphs with annotations explaining what makes them work
  • Sentence rhythm patterns (short declarative then expansion)
  • How to introduce quotes (context → quote → meaning for reader)
  • Analogy style (nature, concrete, 1-2 sentences, no over-explaining)
  • Paragraph opening patterns (quiet observations, not transitions)
  • How to handle difficulty (name the tension directly, sit with it)
  • Natural vocabulary vs. avoided vocabulary

create brief/rubric.md — 7-dimension grading rubric

Scoring system used by the grade-module skill and at quality gates.

Dimensions: Specificity, Voice, Rhythm Variation, Structural Courage, AI Pattern Absence, Emotional Honesty, Discussion Readiness. Each scored 1-5.

Must include:
  • 1/3/5 calibration descriptions for each dimension
  • One LOW calibration example (polished-but-empty AI text)
  • One HIGH calibration example (from Module 08 v2)
  • Phase-adjusted expectations table (discovery vs investigation vs consolidation)
  • The complete judge prompt (for use in a fresh Claude context)
  • Gate thresholds: 28/35 for Phase 2.5, 32/35 for Phase 4.5
Source: writing-best-practices.html Section 5.

create brief/samples/08-prayer-v2.md — Benchmark module

Copy Module 08 v2 into samples. This is the reference every future draft is measured against.

cp content/modules/08-prayer/drafts/v2.md content/brief/samples/08-prayer-v2.md
Add a header comment explaining why this is the benchmark.

update brief/style.md — Expanded anti-patterns

Add the structural tells, rhythm requirements, and permitted imperfections from the writing research.

Add sections:
  • Structural Tells: copula avoidance, rule-of-three, formulaic transitions, summary conclusions, uniform paragraph length
  • Rhythm Requirements: no 3 consecutive sentences within 5 words of each other
  • Permitted Imperfections: fragments OK, "And"/"But" sentence starters OK, varied paragraph lengths OK
  • Expanded banned words: the full list from writing-best-practices.html
Source: process-upgrade-proposal.html Section 4.

update brief/process.md — Quality gates

Add Phase 2.5 (Humanize + Grade) and Phase 4.5 (Final Grade). Add the skeptic's checklist to Phase 3.

  • Phase 2.5: Run humanizer, then grade against rubric. Must score 28/35 to advance.
  • Phase 3 update: Add skeptic's checklist (6 questions) and persona lens.
  • Phase 4.5: Score rewrite against rubric. Must score 32/35 and pass all 6 checklist items.
Source: process-upgrade-proposal.html Sections 2 and 5.

create content/.claude/skills/grade-module/ — Grading skill

Reads a module draft, scores it against the rubric, generates report.html.

Trigger: "grade this," "score this draft," "evaluate module X," "generate report for module X"

Workflow:
  1. Read brief/rubric.md for dimensions and calibration examples
  2. Read brief/voice.md for voice reference
  3. Read brief/audience.md and the module's metadata.yaml for phase
  4. Read the latest draft in the module's drafts/ folder
  5. Score on all 7 dimensions with quoted evidence
  6. Run the skeptic's checklist (6 items, pass/fail)
  7. Check style guide compliance mechanically (em dashes, citations, word count, block quotes)
  8. Generate report.html in the module folder with all results
Output: modules/XX-name/report.html — visual report with scores, evidence, pass/fail, timestamp.

install .claude/skills/humanizer/ — AI pattern removal

Adapted from blader/humanizer. Lives at repo root (useful for content and web copy).

  1. Clone or download blader/humanizer SKILL.md

  3. Add the module project's banned words list to its pattern library

Trigger: "humanize this," "clean up AI patterns," or used in the Phase 2.5 workflow.
